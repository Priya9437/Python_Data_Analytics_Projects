# 📊 Festive Retail Sales Analytics (Python EDA Project)

## 📌 Project Overview
This project focuses on **Exploratory Data Analysis (EDA)** of retail sales data collected during peak festive seasons (Diwali & Dussehra). The goal of this analysis is to uncover hidden consumer shopping trends, evaluate product performance, and provide data-driven insights to optimize inventory and maximize revenue for upcoming festive sales.

## 🛠️ Tech Stack & Libraries Used
* **Language:** Python 🐍
* **Environment:** Jupyter Notebook / VS Code
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn

## 🔍 Key Insights & Business Queries Solved
1. **Demographic Analysis:** Identified the top-spending age groups and gender distributions driving maximum sales.
2. **Geographical Trends:** Mapped out high-performing states and zones to target marketing campaigns.
3. **Product Performance:** Analyzed product categories (Electronics, Clothing, Footwear) with the highest order volume and profit margins.
4. **Customer Behavior:** Calculated average order value (AOV) based on occupation and marital status.

## 📂 Repository Structure
* `Festive_Retail_Sales_EDA.ipynb`: Complete Python source code with detailed data cleaning and visualizations.
* `Festive_Sales_Data.csv`: The clean retail dataset used for the analysis.
* `Festive_Sales_Business_Summary.md`: Executive summary of key business recommendations for stakeholders.
